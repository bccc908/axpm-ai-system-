## 每天怎么开

**终端 1 — 启动应用**

```bash
cd "/Users/kayden/axpm- ai-system"
npm run system
```

**终端 2 — 公网隧道（让别人能打开 talent 域名）**

```bash
cd "/Users/kayden/axpm- ai-system"
npm run go-live
```

保持两个窗口开着。Mac 重启后需重新运行。

## 面相分析（推荐流程）

1. 打开 **命理运势** → 选 **面相**
2. 上传 **正脸照**（光线足、无遮挡）
3. **命理资料** 填好生日 + **出生时间**
4. 可选：**补充描述**（眉、眼、鼻、口、气色）
5. 点 **开始面相分析**（约 10–25 秒）

**原理：** 视觉 API 识别五官 → DeepSeek 写深度解读（含易经卦象 + 奇门遁甲）。

**分享：** 结果下方 → **选择平台分享** 或 **复制分享链接**  
朋友打开：`https://talent.kaydenchiew.com/share/fortune/xxxxx`（无需登录）

## 必配 API（`.env.local`）

| 用途 | 变量 |
|------|------|
| 深度文案（命理、面相、CRM AI） | `DEEPSEEK_API_KEY` |
| 看照片五官 | `GEMINI_API_KEY` 或 `OPENAI_API_KEY`（任选） |
| Telegram 提醒 | `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` |
| 邮件 SMTP | `EMAIL_SMTP_USER` + `EMAIL_SMTP_PASS`（Gmail 用应用专用密码） |
| WhatsApp | `WHATSAPP_ACCESS_TOKEN` + `WHATSAPP_PHONE_NUMBER_ID`（页面：`/dashboard/whatsapp`） |
| 公网域名 | `NEXT_PUBLIC_APP_URL=https://talent.kaydenchiew.com` |
| Cloudflare 隧道 | `CLOUDFLARE_TUNNEL_TOKEN` |

复制模板：`cp .env.example .env.local`

## 常用命令

```bash
npm run system          # 构建 + 启动（生产模式）
npm run system:stop     # 停止
npm run go-live         # 应用 + talent 公网隧道
npm run go-live-quick   # 临时公网链接（无需 token）
npm run cron:tick       # 跑一遍自动化（邮件、digest 等）
npm run setup-talent-domain  # 切换/检查 talent 域名配置
```
